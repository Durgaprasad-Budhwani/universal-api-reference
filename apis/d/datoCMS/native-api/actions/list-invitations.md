# List Invitations with DatoCMS

Retrieves invitations from DatoCMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/site-invitations`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [List Invitations](https://www.datocms.com/docs/content-management-api/resources/site-invitation/instances)
