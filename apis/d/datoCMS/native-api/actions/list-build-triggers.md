# List Build Triggers with DatoCMS

Retrieves build triggers from DatoCMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/build-triggers`
- **Base URL:** `https://site-api.datocms.com`
- **Official documentation:** [List Build Triggers](https://www.datocms.com/docs/content-management-api/resources/build-trigger/instances)
