# List Subscribed Projects with D-Tools SI

## Endpoint

- **Method:** `GET`
- **Path:** `Subscribe/Projects`
- **Base URL:** `https://api.d-tools.com/SI/`
- **Official documentation:** [List Subscribed Projects](https://api.d-tools.com/si/doc/Api/GET-Subscribe-Projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projects` | query | `string` | no |
| `totalCount` | query | `string` | no |
