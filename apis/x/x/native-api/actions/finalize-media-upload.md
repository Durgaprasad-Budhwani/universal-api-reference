# Finalize Media Upload with X

## Endpoint

- **Method:** `POST`
- **Path:** `/2/media/upload/:id/finalize`
- **Base URL:** `https://api.x.com`
- **Official documentation:** [Finalize Media Upload](https://docs.x.com/x-api/media/finalize-media-upload)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Media ID returned by Initialize Media Upload. |
