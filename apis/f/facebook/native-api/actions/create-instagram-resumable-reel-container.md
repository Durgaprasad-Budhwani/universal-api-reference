# Create Instagram Resumable Reel Container with Facebook

## Endpoint

- **Method:** `POST`
- **Path:** `https://graph.facebook.com/v26.0/:instagramAccountId/media`
- **Base URL:** `https://graph.facebook.com/v25.0`
- **Official documentation:** [Create Instagram Resumable Reel Container](https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/media)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `instagramAccountId` | path | `string` | yes | — |
| `caption` | query | `string` | no | Maximum length: 2200. |
